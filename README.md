# Context Pack

Demo built by Vinil Polepalli (vinilpolepalli.com) as a project for Financial Datasets (financialdatasets.ai).

Assembles a selected fundamentals pack (12 quarters, ~10 metrics) for NVDA, Microsoft, Coca-Cola and Goldman from SEC EDGAR XBRL companyfacts, then shows the charts and deterministic answers an agent gets from a few KB of structured data. It is a selected-metrics pack, not a replacement for the full filing.

Static export of a Next.js app. Built with Claude Code.
